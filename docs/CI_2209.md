# The GD 2.2091 CI build (Geode 6, Windows preview)

Two workflows build two files from the same commit:

| | GD 2.2081 (Geode 5) | GD 2.2091 (Geode 6) |
|---|---|---|
| Workflow | `.github/workflows/multi-platform.yml` | `.github/workflows/multi-platform-2209.yml` |
| Platforms | Windows, macOS, iOS, Android 32/64 | Windows only (Mac and Android in 2.0.1, iOS waits for Geode's bindings) |
| Artifact | `GucciBot (all platforms)` | `GucciBot GD 2.2091 (Geode 6, Windows)` |
| File in it | `nigelx1.guccibot.geode` (the release step renames it `nigelx1.guccibot2208.geode`) | `nigelx1.guccibot2209.geode` |
| SDK | from mod.json (5.10.1) | tag 6.0.0-alpha.2 |
| Bindings | `bindings-ref: d641858` in the workflow | 7a670e9 + `patches/bindings-g6-copyable-renames.patch`, from CMakeLists.txt (no `bindings-ref`, which would skip the patch) |
| build-geode-mod | `@61a56c6` (pinned, build 2026-11-17-c) | `@61a56c6` (pinned) |
| Geode CLI | latest | v4.0.1 |
| SafetyHook | `#f44cc07` (pinned, one line in CMakeLists.txt for both builds) | `#f44cc07` (pinned) |
| Install | `install_ci_build.bat [commit]` into the game Geode's CLI points at | `install_ci_build.bat -Gd2209 -Folder <copy> [-Commit <sha>]`, only into a test copy |

The 2.2091 workflow runs on `workflow_dispatch` (any branch: `gh workflow run multi-platform-2209.yml --ref <branch>`) and on pushes to port-2209 and master, so every push to master makes both packages from one commit. Its last step checks the package before uploading it: the binary, the seven FFmpeg DLLs, mod.json saying geode 6.0.0-alpha.2 and gd `{win: 2.2091}`, no other platform's binary, and an about.md that says 2.2091 and not 2.2081.

## Pinned on both (done)

Master pinned the 2.2081 workflow's two floating inputs in build 2026-11-17-c (3be37e4), to the commits the build already used, so the 2.2081 file didn't change: `geode-sdk/build-geode-mod@61a56c697aea9655e3f31c6c1b83870431f30434` on both `uses:` lines of multi-platform.yml, and `gh:cursey/safetyhook#f44cc070a8340f2f26649553c49533475417304d` in CMakeLists.txt. With the 2.2091 code merged into master, CMakeLists.txt has one pinned SafetyHook line for both builds.

Both actions still use `geode-sdk/cli/.github/actions/setup@main` inside themselves. That can't be pinned without a fork of the action.
