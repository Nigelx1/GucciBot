# In-game test pass, 2026-11-12

Claude's unattended runs from the evening of 2026-11-11 into the morning of 2026-11-12, while Nigel slept. It follows docs/TEST_PASS_2026-11-10.md (parts 1 to 6). Four runs:
- **Part 1, the ladder baseline:** tiers 4 to 6 of Nigel's ladder on the Search Pathfinder, build 2026-11-10-co.
- **Part 2, Ship Steering's reaction clock:** build 2026-11-11-a, KOCMOC UNLEASHED.
- **Part 3, deaths the simulation missed:** builds 2026-11-12-a to -h.
- **Part 4, Try other routes at dead ends:** builds -i to -o.

- **Games:** the Pathfinder runs used the gdcopy_ai test copy (GDAi.exe); the clock runs used the gdcopy_sync copy (GDLab.exe, port 8801). Each was started with safe mode forced, muted, minimized and off-screen, at BelowNormal priority, and closed in a finally. Nigel's game, saves and mods folder were never touched. No test game is left running (checked for GDAi.exe and GDLab.exe by name).
- **Cold:** a fresh game for each level, no macro loaded, from 0%, Remember solutions off. Every 100% got a cold replay: the level reopened, the saved file loaded by name and played from 0%. Every saved macro was deleted afterward.
- **One run per level** unless it says otherwise. Times and click rates vary a lot from run to run, so a single pass or fail isn't a pass rate.
- **Evidence** (the printed output of every test, in the scratchpad): ladder\ (RESULTS.md, results\, abspf_<level>.log), steer_clock\ (PROGRESS.md, deltas_*.txt, sdeltas_*.txt, vscounter_Q1.txt, vscounter_QK1.txt, FQ1_steer_tags.txt), mismatch\ (PROGRESS.md, miss_*.json, .log and _stdout.txt, probe_*.json, aim_gr6.json, replay_*.json), fix1\ (PROGRESS.md, out_<run>.txt, results\, abspf_<run>.log).

## Part 4: Try other routes at dead ends (builds -i to -o)

-i adds the saved switch (Pathfinder page, off by default): when the search keeps dying at one spot, it may go back and take another orb, pad, portal or trigger. The idea is camila314's, taken from notes on her method; none of her code is in it. -j logs why a stop found no other route; -k also marks the route it left as dead; -m fixes log wording; -n makes sim_vs_real's watch mode clean up even when a run throws, and labels its fields; -o keeps a dead end's route blocked for that stop and every earlier stop of the same spot. -l (a fix to quiet test launches) is another session's.

|---|---|---|
| Forest Temple | 83.95%, 538.6 s (-i) | 83.95%: 544.2 s (-i), 405.1 s (-k), 549.6 s (-o) |
| LIMBO | 10.03%, 1029.3 s (-i) | 10.03%, 1029.6 s (-i) |
| Bloodbath | 100%, 352.0 s, replay complete 118.5 s (-l, which has -k) | 100%: 705.4 s (-i), replay 117.5 s; 442.9 s (-k), replay 117.7 s. 99.10%, stalled at tick 27341 after 765.7 s (-o) |
| The Nightmare | - | 100%, 180.8 s, replay complete 93.5 s (-i) |
| Time Machine | - | 100%, 140.6 s, replay complete 99.6 s (-i; run by mistake instead of Clubstep) |

- **Forest Temple:** the switch never took another route. On -o the spot near the tick-17016 death went back far enough for the switch to act (floor 15576 -> 15336), and every stop from tick 16152 to 16931 said "of 8 ideas looked at, 8 take the dead end's route, 0 of another die within 30 ticks of their fork". So the ideas there don't vary the route at all; an earlier guess (other routes dying past a fork) was wrong.
- **LIMBO:** stuck at x 7576 (tick 5963) both ways. That spot never went back far enough for the switch to act.
- **Bloodbath:** the switch fired 3 times a run. On -i it took a route at tick 924 and then flipped back (object 668), which led to -k and -o. On -o it blocked that flip-back as meant, then the run went differently, switched at ticks 24942 to 24946 and stalled at 99.10%. With one run I'm not sure -o caused it rather than run-to-run variation. The switch is off by default, so normal play isn't affected.
- **One switch-off Bloodbath run (-k) is not a result:** the game closed mid-search at 211 s with no crash log, right after a normal rewind. I'm not sure why. The rerun is the row above.
- **Not tested:** Clubstep, Theory of Everything 2 and Deadlocked with the switch on (locked in the test save: they need secret coins); -n's two changes in the game (they only change cleanup and what a reply says; the build passed).

**Result:** no level got further with the switch on, and it made Bloodbath slower. It stays off.
